## 1. TELOS + ponytail

A layer's **telos** is the end it exists to serve. Callers **USE** that
end. Re-implementing it elsewhere is bloat even when the clone is thin.

| Layer | Telos (owns) | Must not own |
|-------|--------------|--------------|
| **ux-behavior** | Product meaning → verified `list[Op]`; `MorphState` / `@action`; Cap *policy* (require / trust / stamp) | Raw HTML trees, wire codecs, Cap *crypto*, product `uxcompose` / Clock A |
| **ux-dom** | Tree → HTML, `Document`, `extract_by_id`, `uxdom` | `@action`, MorphState, Intent/Cap |
| **ux-channel** | Intent → Cap → Result; wire; Cap Host; `mount_channel` | HTML serialize, product CLI, MorphState |
| **ux-motion** | Presence / transition plans as data (IR v1) | `@action`, Cap mint, product CLI |
| **ux-compose** | Author composition + `uxcompose` + Clock A + `wire/` | Re-implementing any specialist |
| **cek-host** | Cap mint / verify / project | HTTP Clock A, ux-dom trees |

**Ponytail** (shrink only in this order — never reverse):

1. **YAGNI** — delete the unused plane if no locked L depends on it.
2. **Reuse the owner** — call the specialist / host framework.
3. **stdlib** — only when the owner has no public API yet.
4. **Minimum local** — smallest adapter that keeps Isolation + leftover teaching.

Organize by **capability / happy path**, not by feature folders. One
taught path per job.

**Intent Vector** (required on every DO Soft):

| Field | Meaning |
|-------|---------|
| **Intent** | One capability end (the telos being served) |
| **Vector** | Owner library → behavior USE / leftover site (`path:line`) |
| **Concern** | One Soft; prefer reuse-owner or YAGNI delete over rename |
| **Not** | Folder move, public rename, encyclopedia, sixth product |
